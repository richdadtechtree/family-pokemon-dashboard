# 아빠 포켓몬 연동

## 지금 상황

- 아빠의 포켓몬은 대시보드 '우리 가족 포켓몬' 카드의 아빠 줄에서 본다. 졸업 포켓몬을 들판에 늘어놓는 화면은 만들지 않는다.
- 아이들과 아빠의 수집 기록·경험치·쿠폰은 분리한다. 종류 목록(164종)만 공유한다.
- 알 속 포켓몬은 공개하지 않는다.

## 경험치 — 토큰 사용량

아빠의 포켓몬은 AI 코딩 도구 토큰 사용량으로 자란다. 사용량을 주기적으로 서버에 보내면 서버가 날짜별 최댓값을 쌓아 경험치로 쓴다.

- 흐름: 사용량 보내기(주기적) → 서버가 날짜별 토큰 최댓값을 합산 → `아빠/포켓몬-동료.json` → 화면.
- 경험치 = 날짜별 오늘 토큰의 최댓값을 모두 더한 값 − 알을 받을 때의 값. 같은 날 값은 커지기만 하고, 대화 기록이 지워져도 줄지 않는다.
- 장부는 서버 `~/.config/family-dashboard/dad-pokemon.json`(위키 밖)이다. **지우거나 덮어쓰면 키우던 알이 바뀐다.**
- 부화·진화·졸업 기준은 `dashboard/deploy/dad-growth.json`: 부화 156,000,000 / 2단계 진화 누적 312,000,000 / 졸업 누적 468,000,000 토큰.
- `아빠/포켓몬-동료.json`은 서버에서만 만든다. GitHub에 올리지 않는다(`.gitignore`).
- 사용량을 보내는 방법이 없으면(연동을 안 하면) 아빠 포켓몬은 자라지 않는다. 대시보드의 아빠 줄은 알 상태로 보인다.
- 공개 데이터는 토큰 수·동료·이미 만난 모습·졸업 도감이다. 비용·대화·로그 경로·키는 내보내지 않는다.

## 공통 목록 관리

- 정본: `dashboard/js/pokemon.js`.
- `node dashboard/deploy/build-family-catalog.cjs`로 `family-catalog.json`을 생성한다.
