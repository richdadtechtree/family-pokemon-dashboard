# 가족 포켓몬 대시보드

아이 루틴을 마치면 포켓몬 알이 부화하고 진화하는 가족 대시보드입니다. 달력, 할 일, 장보기, 여행 준비물, 포켓몬 동산, 놀이방을 한 화면에 보여 줍니다. 아이가 루틴을 하면 포켓몬이 자라고, 다 키우면 동산으로 가고 새 알이 옵니다.

> **비공식 팬 프로젝트입니다.** 포켓몬은 Nintendo · Creatures Inc. · GAME FREAK inc.의 등록 상표입니다. 이 프로젝트는 포켓몬스터와 아무 관련이 없고, 상업적 목적이 없습니다. 포켓몬 이름·그림은 설명을 위해 쓸 뿐 권리를 주장하지 않습니다.
>
> 이 저장소에 들어 있는 가족 정보는 전부 예시입니다. 첫째·둘째라는 이름, 일정, 루틴은 받은 사람이 자기 가족 것으로 고쳐 쓰면 됩니다. 아래 "5. 자기 가족에 맞게 바꾸기"를 보세요.

## 0. 이게 뭔가요? 한눈에 보기

- **아이한테는 게임 같은 루틴표.** 아침 양치, 독서 15분 같은 루틴을 누르면 포켓몬 레벨이 오릅니다.
- **부모한테는 가족 위키.** 일정, 할 일, 장보기, 여행 준비물을 글로 적어두면 대시보드가 알아서 화면에 보여 줍니다.
- **데이터는 글로 된 파일(Markdown)입니다.** 엑셀도, 앱도 아닙니다. 메모장으로도 고칠 수 있는 글 파일이 곧 데이터입니다. 대시보드는 이 글 파일을 2분마다 다시 읽습니다.
- **예시 화면이 바로 뜹니다.** 받자마자 실행만 하면 예시 가족(첫째·둘째)으로 전체 화면을 볼 수 있습니다. 자기 가족 정보는 나중에 천천히 바꾸면 됩니다.

## 1. 준비물

- **Python 3** 하나만 있으면 됩니다. 따로 설치할 프로그램은 없습니다.
  - 윈도우: [python.org](https://www.python.org/downloads/)에서 받아 설치합니다. 설치할 때 **"Add Python to PATH"**에 체크하는 걸 잊지 마세요.
  - 맥: 터미널에서 `python3 --version`을 쳐서 버전이 나오면 이미 있습니다. 안 나오면 python.org에서 받습니다.
- 인터넷은 처음 받는 데만 필요합니다. 받은 뒤에는 집 안에서만 써도 됩니다.

## 2. 빠른 시작 — 받자마자 예시 화면 보기

### 1단계. 받기

터미널(윈도우는 PowerShell이나 명령 프롬프트, 맥은 터미널)을 열고, 원하는 폴더에서 아래 명령을 그대로 복사해 붙여넣습니다.

```bash
git clone https://github.com/richdadtechtree/family-pokemon-dashboard.git
cd family-pokemon-dashboard
```

> git이 없으면: GitHub 페이지에서 초록색 **Code** 버튼 → **Download ZIP**을 눌러 받은 뒤 압축을 풉니다. 푼 폴더 안에서 다음 단계를 합니다.

### 2단계. 켜기

받은 폴더 안에서 아래 명령을 실행합니다.

```bash
python3 dashboard/serve.py
```

- 윈도우는 `python`으로 씁니다: `python dashboard/serve.py`
- `Serving on port 8000` 같은 말이 나오면 켜진 겁니다. 이 창은 켜둔 채로 둡니다. 끄려면 `Ctrl + C`를 누릅니다.

### 3단계. 브라우저로 열기

브라우저(크롬, 사파리, 엣지 등) 주소창에 아래를 입력합니다.

```
http://localhost:8000/dashboard/
```

### 4단계. 예시 화면 먼저 보기

예시 가족으로 전체 화면을 보려면 주소 뒤에 `?demo`를 붙입니다.

```
http://localhost:8000/dashboard/?demo
```

예시 화면에서는 눌러보고 돌아다녀도 저장이 안 됩니다. "예시 화면에서는 저장하지 않아요"라는 말이 뜨면 정상입니다. 진짜로 쓰려면 3단계 주소(`?demo` 없는 주소)로 열고, 아래 5번 절대로 가족 정보를 바꾸면 됩니다.

### 다른 기기(거실 태블릿, 폰)에서도 보기

같은 집 와이파이 안에서 다른 기기로 보려면, 켤 때 `--lan`을 붙입니다.

```bash
python3 dashboard/serve.py --lan
```

그러고 나서 태블릿·폰 브라우저에서 `http://<이 컴퓨터 IP>:8000/dashboard/`를 엽니다. 이 컴퓨터 IP는 윈도우에서 `ipconfig`, 맥에서 `ifconfig`로 확인합니다(보통 `192.168.0.○○` 모양).

### 알아두면 좋은 켜는 법

- 포트를 바꾸려면: `python3 dashboard/serve.py --port 8080` (그러면 주소도 `:8080`으로 바뀝니다)
- 글 파일 자동 저장 기록(git 자동 커밋)을 끄려면: `python3 dashboard/serve.py --no-git`
- 파일을 더블클릭으로 열면 브라우저 보안 때문에 위키를 못 읽습니다. 꼭 위처럼 서버로 켜세요.

## 3. 화면 설명

### 대시보드 (처음 화면)

- **달력** — 오늘·내일 일정, 이번 달 달력. 빨간 날은 날짜 숫자가 빨갛게 보입니다.
- **할 일 · 장보기 · 준비물** — 오늘 할 일과 장보기 목록. 체크하면 그날만 체크 표시가 되고, 다음 날이면 다시 풀립니다. 준비물은 날짜가 있는 것은 당일만 보이고, 내일 것은 전날 낮 12시부터 보입니다.
- **여행 준비물** — 여행 갈 때 챙길 것. 대시보드에서 눌러 체크하고 다시 풀 수 있습니다.
- **"○○는 지금"** — 지금 시간에 아빠·엄마·아이들이 뭘 하는지 보여 주는 카드입니다. 시간표는 `일정/하루 일과.md`에서 바꿉니다.
- **날씨 · 미세먼지** — 오늘 날씨와 미세먼지. 위치는 기본 서울입니다(바꾸는 법은 5번 절).
- **다가오는 날** — 생일 같은 날을 D-day 순으로 최대 5개 보여 줍니다.
- **우리 가족 포켓몬** — 아이들 포켓몬이 지금 몇 레벨인지, 동산에 몇 마리인지 한눈에 봅니다. 아이를 누르면 그 아이 동산으로 갑니다.
- **지수 칸** — 아래쪽에 코스피·코스닥·S&P·나스닥이 오늘 얼마나 오르고 내렸는지, 최고점보다 얼마나 떨어졌는지 나옵니다. +2% 이상 급등하면 메인 화면 위쪽에 노란 알림이 떠 있고, 누르면 지수 칸으로 내려갑니다. (지수 실시간 가격은 따로 연결해야 뜹니다. 9번 절을 보세요.)

### 아이 할 일 화면 (아이마다 따로)

- 상단 메뉴에서 아이 이름을 누르면 그 아이 화면이 열립니다. 로그인은 없습니다. 아이가 자기 이름을 눌러 들어가면 그 아이 것입니다.
- **오늘 루틴** — 아침·저녁 루틴 목록. 누르면 체크되고 포켓몬 레벨이 1 오릅니다. 다시 누르면 풀립니다.
- **오늘의 영어** — 아래 "영어 퀴즈"를 보세요.
- **🪙 토큰** — 머리줄 오른쪽에 아이가 가진 토큰이 보입니다.
- **👕 옷 갈아입기** — 아이가 가진 옷을 고릅니다. 상점도 여기 있습니다.
- **🏦 은행가기** — 토큰을 맡기고 이자를 받습니다.

### 동산 (아이마다 따로)

- 다 키운(졸업한) 포켓몬들이 들판에 모여 있습니다.
- 왼쪽에는 "지금 키우는 포켓몬"이 보입니다. 그림, 단계, 진화 사슬, 레벨이 나옵니다.
- 동산 포켓몬을 눌러 **풀어주기**를 하면 토큰을 받습니다. 풀어준 포켓몬은 도감에는 그대로 남습니다.

### 도감

- 지금까지 만난 포켓몬이 모여 있습니다. 못 만난 칸은 그림자 그대로, 이름은 `?`로 보입니다.
- 포켓몬 이름 옆에는 등급 배지가 있습니다. 등급은 종족값 기준입니다. SS 680 / S 600 / A 518~545 / B 480~515 / C 400~479 / D 400 미만. 게을킹만 특성 때문에 A입니다.

### 놀이방

상단 메뉴 "놀이방"에서 들어갑니다. 들어갈 때 이름을 고릅니다(첫째·둘째·아빠·엄마). 점수는 사람마다 따로 저장됩니다. 아이가 실제로 논 시간 10분마다 토큰 1개가 생깁니다(아이만).

- **숫자 게임** — 60초 동안 덧셈·뺄셈을 풉니다. 정답 10점. 10개 맞히면 다음 목표가 10씩 늘어납니다.
- **코딩 로봇** — 명령 블록으로 로봇을 움직여 20단계를 깹니다.
- **우주수식 사령관** — 내려오는 적을 수식으로 물리칩니다.
- **맞춤법 몬스터 배틀** — 맞춤법 문제를 맞히면 내 포켓몬이 공격합니다. 단계가 올라갈수록 강한 적이 나옵니다.
- **경마 (공통 게임)** — 2~10명을 골라 말을 달립니다. 말 이름은 매번 새로 뽑습니다.

### 상점 · 은행 · 토큰

- **토큰이 생기는 길은 딱 두 가지입니다.** 동산 포켓몬 풀어주기(등급별 D=50 · C=60 · B=70 · A=80 · S=90 · SS=100)와 놀이방 게임 시간(10분마다 1토큰, 아이만)입니다. **루틴을 해도 토큰이 안 생기고, 퀴즈를 맞혀도 토큰이 안 됩니다.**
- **상점** — 옷·신발·원피스·패딩을 토큰으로 삽니다. 원피스(여자 아이만) 4색 중 1번 분홍은 무료, 2~4번은 5토큰. 신발 5토큰, 검정 패딩 6토큰, 남자 코디 4번 농구 유니폼·5번 공룡 후드티 5토큰. 산 옷은 가진 것이 되어 상점에서 사라집니다.
- **은행** — 토큰을 맡기면 매일 이자가 붙습니다. **단리**(원금에만 이자)입니다. 기간은 7일(하루 10%) · 14일(15%) · 21일(20%) · 28일(25%)만 고를 수 있고, 만기가 되면 원금+이자를 찾습니다.

### 오늘의 영어 (영어 퀴즈)

- 아이마다 하루 한 문제. 그림을 보고 단어 4개 중 하나를 고릅니다.
- 맞히면 **🔊 들어 보기**와 **🎤 따라 읽기**(음성 인식)가 나옵니다. 따라 읽기에 성공하면 ⭐ 스티커 1장을 받고 포켓몬 레벨이 1 오릅니다.
- 음성 인식이 안 되는 기기는 부모가 **"들었어요"** 버튼을 눌러 줄 수 있습니다. 그러면 스티커는 아이가 다음에 동산에 들어갈 때 팝업으로 뜹니다.
- 아이들 모두가 오늘 받으면 "영어 팀 완성!"이 됩니다.
- 하루에 아이당 1장만 받을 수 있습니다. 틀린 단어는 다음에 다시 나옵니다.

### 가족회의 · 회의 아이디어

- **🗣️ 가족회의** — 날짜별 회의록. 주제, 의견, 정한 것, 할 일을 적습니다. 지난 회의는 날짜를 골라 봅니다.
- **💡 회의 아이디어** — 이번 주 주제와 의견을 포스트잇 화이트보드로 모읍니다. 주제를 바꾸거나 회의를 끝내면 지난 주제로 옮겨집니다.

### 사진 액자 · 절전 시계

- 5분 동안 아무도 안 만지면 큰 시계 화면만 나옵니다. 밤 10시~아침 6시에는 어두운 화면에 작은 시계가 나옵니다. 화면을 한 번 누르면 대시보드로 돌아옵니다.

## 4. 포켓몬 키우는 법

### 기본 규칙 — 루틴 1개 = 레벨 1

- 아이 루틴을 하나 마치면(화면에서 누르면) 지금 키우는 포켓몬 레벨이 1 오릅니다.
- **알 Lv.5에서 부화**합니다. 부화하면 레벨이 1부터 다시 시작합니다.
- **1단계 Lv.10에서 진화**합니다. 진화해도 레벨이 1부터 다시 시작합니다.
- **2단계 Lv.15에서 최종 진화**하면 동산으로 이동하고, 새 알이 레벨 0부터 시작합니다.
- 그래서 **포켓몬 한 마리를 졸업시키는 데 루틴 28개**가 필요합니다. 알 5개 + 1단계 9개 + 2단계 14개입니다. 부화하는 그 루틴부터 1단계 레벨 1, 진화하는 그 루틴부터 2단계 레벨 1로 세기 때문입니다.

### 보너스

- **🎁 하루 완료 보너스** — 그날 해야 할 루틴을 모두 하면 레벨 +2줄이 붙습니다. 하나라도 취소하면 두 줄도 빠집니다.
- **🤝 형제 보너스** — 아이들이 그날 모두 하루 완료를 하면 각자 레벨 +1줄이 붙습니다.
- **🏪 쿠폰** — 월~금(빨간 날 제외)을 모두 하루 완료하면 그 주 마지막 등교일에 다이소·편의점 자유 이용권(5,000원까지) 1장이 생깁니다.

### 어떤 포켓몬을 키우는지

- `아이들/포켓몬 알.md` 표가 정합니다. 첫 포켓몬은 첫째 파이리(도감 4번), 둘째 꼬부기(도감 7번)입니다.
- 한 마리를 다 키우면 알 3개가 오고, 아이가 대시보드에서 하나를 고릅니다. 알은 5% 확률로 전설 포켓몬이고, 뮤도 들어 있습니다.
- 알인 동안에는 어떤 포켓몬인지 보이지 않습니다. 알 색은 타입 힌트입니다(🔥 불꽃 알 등).
- 아이마다 이미 키운 포켓몬은 다시 나오지 않고, 164종을 다 키우면 처음부터 다시 나옵니다.
- **적힌 줄은 고치거나 지우지 마세요.** 키우던 포켓몬이 바뀝니다. 아이 이름이 바뀌면 이 표의 이름도 함께 바꿉니다.

### 동산에서 풀어주기

- 동산 포켓몬을 풀어주면 등급별 토큰을 받습니다(D=50 · C=60 · B=70 · A=80 · S=90 · SS=100). 도감에는 그대로 남습니다.

## 5. 자기 가족에 맞게 바꾸기

이 저장소의 글 파일은 전부 예시입니다. 아래 순서대로 바꾸면 됩니다. 글 파일은 메모장, VS Code 같은 글 편집기로 고치면 됩니다. **저장하면 대시보드가 2분 안에 다시 읽어 화면에 반영합니다.**

### 5-1. 이름·생일 바꾸기

- `가족 구성원.md` — `## 우리 가족` 표(아빠·엄마 생일)와 `## 아이` 표(이름·생일)를 고칩니다.
- 이름을 바꾸면 위키 파일 속 예시 이름(첫째·둘째)도 함께 바꿉니다. 대시보드는 글 파일에 적힌 이름으로 아이를 구분합니다.

### 5-2. 루틴 바꾸기

- `아이들/루틴.md` — 아침·저녁 루틴 목록을 고칩니다. 시간 칸에 `평일`이라고 적으면 주말·빨간 날에는 안 나옵니다.
- `일정/일정표.md` · `일정/가족 연간 일정.md` · `일정/하루 일과.md` — 약속, 해마다 오는 날, 아빠·엄마 시간표를 고칩니다.
- `장보기·할 일.md` · `여행/다음 여행.md` — 목록을 비우고 새로 적습니다.

### 5-3. 아이 수·이름·성별 바꾸기 (가장 중요 — 세 곳을 함께 고칩니다)

기본은 아이 2명(첫째 남자 아이, 둘째 여자 아이)입니다. 바꾸려면 **세 곳을 똑같이** 고칩니다.

**1곳 — `가족 구성원.md` `## 아이` 표**

이름을 고치고, 아이를 늘리거나 줄이면 줄을 더하거나 뺍니다.

**2곳 — `dashboard/js/config.js` `KID_PROFILES`**

이름·성별 목록입니다. 셋째를 더할 때는 아래처럼 한 줄을 더합니다.

```js
const KID_PROFILES = [
  { name: "첫째", gender: "boy" },
  { name: "둘째", gender: "girl" },
  { name: "셋째", gender: "boy" },   // 셋째를 더할 때
];
```

성별은 옷 상점에서 무엇을 보여줄지를 정합니다. 남자 아이에게는 남자 코디, 여자 아이에게는 원피스·상의·하의가 보입니다. 아이를 1명으로 줄이면 한 줄을 빼면 됩니다. 아이가 3명을 넘으면 아이 색이 차례로 돌아가며 쓰입니다.

**3곳 — `dashboard/serve.py` `KID_PROFILES`**

서버 쪽 같은 목록입니다. 딕셔너리 형태라 아래처럼 생겼습니다. 이름·성별을 똑같이 고칩니다.

```python
KID_PROFILES = {"첫째": "boy", "둘째": "girl"}
```

### 5-4. 포켓몬 계보 바꾸기

- 첫 포켓몬을 바꾸려면 `아이들/포켓몬 알.md` 표의 첫 줄 도감번호를 바꿉니다. (도감번호는 포켓몬 도감 번호입니다. 예: 파이리 4, 꼬부기 7, 피카츄 25)
- **이미 키우고 있는 줄은 고치지 마세요.** 키우던 포켓몬이 바뀝니다.
- 처음부터 다시 시작하려면 `아이들/포켓몬 기록.md` · `아이들/포켓몬 알.md` · `아이들/동산 장부.md` · `아이들/토큰.md` · `아이들/은행.md` · `아이들/쿠폰.md` · `아이들/성장 기록.md`의 예시 줄을 지우고 표 머리말만 남깁니다. 첫 포켓몬은 `아이들/포켓몬 알.md`에 적힌 대로 옵니다.

### 5-5. 옷·상점 가격 바꾸기

- `dashboard/js/config.js`의 `SHOP` 부분을 봅니다. 옷 이름과 가격(토큰)이 여기 있습니다.
- 예: 원피스 2~4번 가격(기본 5토큰), 신발(5토큰), 검정 패딩(6토큰), 남자 코디 4·5번(5토큰)을 바꾸려면 `SHOP` 안의 숫자를 고칩니다.
- 옷 이름(코디 이름, 원피스 색 이름)도 여기에서 바꿉니다.

### 5-6. 날씨 위치 바꾸기

- `dashboard/js/config.js`의 `CONFIG.location`에서 바꿉니다. 기본은 서울입니다.

### 5-7. 나머지 예시 비우기

- `아이들/캐릭터.md` · `아이들/상의.md` · `아이들/하의.md` · `아이들/머리.md` · `아이들/신발.md` · `아이들/원피스.md` · `아이들/코디.md` · `아이들/패딩.md` — 예시 줄을 지웁니다.
- `가족회의/아이디어.md` · `일정/응원.md` · `연락처.md` — 예시를 지웁니다.

위키 형식 규칙이 더 필요하면 [AGENTS.md](AGENTS.md)를 봅니다. 날짜는 항상 `YYYY-MM-DD`로 적습니다.

## 6. 구글 캘린더 연결하기

주말·특별 일정을 "○○는 지금"과 달력에 보여 주려면 구글 캘린더를 연결합니다.

1. 컴퓨터 브라우저로 Google 캘린더를 엽니다.
2. 왼쪽 목록에서 캘린더 이름 옆 **⋮** → **설정 및 공유**를 누릅니다.
3. 맨 아래 **캘린더 통합** → **iCal 형식의 비밀 주소**를 복사합니다.
4. `dashboard/calendar-url.txt` 파일을 만들어 그 주소를 한 줄로 붙여넣습니다. 그리고 서버를 다시 켭니다.
5. 일정 제목 앞에 이름을 붙입니다. `아빠 골프`, `엄마 필라테스`, `가족 외식`, `[첫째] 태권도`처럼 적습니다. (규칙은 AGENTS.md를 보세요.)

- 비밀 주소는 **캘린더 열쇠**입니다. `calendar-url.txt`는 `.gitignore`에 들어 있어 GitHub에 올라가지 않고, 서버도 이 파일을 밖으로 내보내지 않습니다. 혹시 새어 나가면 같은 화면에서 **재설정**하면 예전 주소는 막힙니다.
- 캘린더는 5분마다 새로 받아 옵니다. 구글 쪽 반영이 늦으면 더 걸릴 수 있습니다.
- 대한민국 공휴일은 구글 공개 캘린더에서 하루 한 번 받아 옵니다. 위키에 적지 않아도 됩니다.

## 7. 비밀번호 걸기

대시보드는 처음 여는 기기에서 가족 비밀번호를 한 번 넣으면 1년 동안 기억합니다.

```bash
python3 dashboard/serve.py --set-password
```

- 비밀번호를 다시 정하면 모든 기기가 로그아웃됩니다.
- 브라우저 주소 뒤에 `/logout`을 붙이면 그 기기만 로그아웃됩니다.
- 비밀번호 암호문은 `dashboard/auth.json`에 저장됩니다. 이 파일은 `.gitignore`에 들어 있어 GitHub에 올라가지 않습니다.
- 비밀번호를 잊었으면 서버에서 다시 `--set-password`로 정하면 됩니다.

## 8. 집 서버에 올려 가족이 함께 쓰기

집 밖에서도 가족이 함께 쓰려면, 항상 켜져 있는 컴퓨터(집 서버, 라즈베리파이, 클라우드 서버 등)에 올립니다.

1. 서버에 이 저장소를 받습니다(`git clone`).
2. `dashboard/deploy/` 폴더를 봅니다.
   - `family-dashboard.service` — systemd 서비스 파일입니다. 컴퓨터를 켜면 대시보드가 저절로 켜지게 합니다. `WorkingDirectory`와 `User`를 자기 환경에 맞게 고칩니다.
   - `nginx-family-dashboard.conf` — nginx HTTPS 설정입니다. 도메인을 자기 것으로 바꿉니다.
   - `Caddyfile.example` — Caddy로 쓰는 경우의 예시입니다.
3. 비밀번호를 걸고(7번 절), 구글 캘린더를 연결합니다(6번 절).
4. 가족 기기에서는 브라우저로 서버 주소에 들어가면 됩니다.

집 안에서만 쓴다면 이 절은 필요 없습니다. 2번 절의 `--lan`이면 충분합니다.

## 9. 선택 기능

### 지수 (코스피·코스닥·S&P·나스닥)

- 이 저장소만으로는 지수 칸에 실시간 가격이 없습니다. 지수 칸에는 "지수를 불러오지 못했어요"가 뜹니다(에러 화면이 아니라 그 칸만 그렇게 뜹니다).
- 실시간 지수를 보려면 지수 모듈을 연결합니다. `INDEX_ATH_PY` 환경변수로 모듈 경로를 알려 주면, 대시보드가 그 모듈의 `compute()`를 5분에 한 번 불러옵니다. 모듈은 `ATH`(장중 최고점 딕셔너리)와 `compute()`(지수별 현재가·오늘 등락·ATH 대비 하락률을 돌려주는 함수)를 제공해야 합니다. ATH 기본값은 `dashboard/serve.py`의 `DEFAULT_ATH`에 들어 있습니다.
- +2% 이상 급등하면 메인 화면에서만 팡파레가 터집니다. 급등이 이어지는 동안은 화면 위 노란 알림이 떠 있고, 누르면 지수 칸으로 이동합니다.

### 아빠 포켓몬 연동 (선택)

- 아빠의 포켓몬은 AI 코딩 도구 토큰 사용량으로 자랍니다. 부화 156,000,000 / 2단계 진화 누적 312,000,000 / 졸업 누적 468,000,000 토큰(`dashboard/deploy/dad-growth.json`).
- 사용량을 서버에 보내는 방법이 없으면 아빠 포켓몬은 자라지 않고 알 상태로 보입니다. 자세한 흐름은 `아빠/포켓몬 연동.md`를 보세요.
- `아빠/포켓몬-동료.json`과 `아빠/토큰-사용량.json`은 서버에서만 만들고 GitHub에 올리지 않습니다.

### 슬랙 봇 (들어 있지 않음)

- 이 저장소에는 슬랙 봇이 들어 있지 않습니다. 위키를 메신저 봇으로 쓰고 싶으면 봇을 따로 만들어 위키 폴더를 읽게 하세요.

## 10. 이 버전에서 빠진 기능

원래 가족이 쓰던 것 중, 공개 버전에는 일부러 빠져 있는 것이 있습니다.

- **부모 할 일 메뉴** — 비밀번호로 여는 부모 전용 화면이 없습니다.
- **매일 기분 고르기 (기분 정원)** — 아이가 매일 기분을 고르고 꽃밭이 자라는 기능이 없습니다.
- **캐릭터 그림** — 아이 캐릭터 그림이 없습니다. 옷을 고르는 화면에서는 이모지(👗👟🧥)로 표시됩니다. 자기 아이 그림을 넣으려면 `dashboard/img/kids/`에 그림을 넣고 `dashboard/js/config.js`를 보면 됩니다.
- **칭찬 스티커 주기** — 부모가 스티커를 주는 메뉴가 없습니다. 스티커는 **영어 퀴즈를 맞혀야** 받을 수 있습니다(하루 1장, 레벨 +1).

## 11. 자주 묻는 질문 · 안 될 때

**Q. 주소를 열었는데 안 떠요.**
- 서버를 켰는지 확인하세요. `python3 dashboard/serve.py`를 실행한 터미널 창이 켜져 있어야 합니다.
- 주소가 맞는지 확인하세요. `http://localhost:8000/dashboard/`입니다. `dashboard` 뒤 `/`까지 적어야 합니다.
- 파일을 더블클릭으로 열면 안 됩니다. 꼭 서버로 켜서 주소로 여세요.

**Q. 예시 화면(`?demo`)이 안 떠요.**
- `http://localhost:8000/dashboard/?demo` — `?demo`가 `dashboard/` 뒤에 붙었는지 확인하세요.
- 그래도 안 되면 서버를 껐다가 다시 켜 보세요.

**Q. "포트가 이미 쓰이고 있어요" 같은 에러가 떠요.**
- 8000번 포트를 다른 프로그램이 쓰고 있는 겁니다. 포트를 바꿔 켜세요.
  ```bash
  python3 dashboard/serve.py --port 8080
  ```
  그러면 주소도 `http://localhost:8080/dashboard/`가 됩니다.

**Q. 글 파일을 고쳤는데 화면이 안 바뀌어요.**
- 대시보드는 글 파일을 2분마다 다시 읽습니다. 2분 기다렸다가 브라우저를 새로고침(`Ctrl + R` 또는 `Cmd + R`)하세요.
- 코드(`dashboard/js/`, `dashboard/css/`)를 고쳤으면 열린 대시보드가 저절로 새로고침됩니다. 안 되면 직접 새로고침하세요.

**Q. 구글 캘린더 일정이 안 보여요.**
- `dashboard/calendar-url.txt`에 비밀 주소가 한 줄로 제대로 들어갔는지 확인하세요. 앞뒤 공백이 있으면 안 됩니다.
- 캘린더는 5분마다 새로 받아 옵니다. 조금 기다려 보세요.
- 일정 제목 앞에 이름(`아빠 골프`, `[첫째] 태권도`)이 없으면 "○○는 지금"에는 안 나오고 달력·오늘 목록에만 나옵니다.

**Q. 비밀번호를 잊었어요.**
- 서버에서 다시 정하면 됩니다.
  ```bash
  python3 dashboard/serve.py --set-password
  ```

**Q. 루틴을 해도 토큰이 안 쌓여요.**
- 정상입니다. 루틴은 포켓몬 레벨만 올리고 토큰은 안 줍니다. 토큰은 동산 포켓몬 풀어주기와 놀이방 게임 시간으로만 생깁니다.

**Q. 퀴즈에서 "따라 읽기"가 안 돼요.**
- 음성 인식은 브라우저마다 되고 안 되고가 다릅니다. 안 되면 부모가 **"들었어요"** 버튼을 눌러 주면 됩니다. 스티커는 아이가 다음에 동산에 들어갈 때 뜹니다.

**Q. 아이를 3명으로 늘리고 싶어요.**
- 5-3번 절을 보세요. `가족 구성원.md` 표, `dashboard/js/config.js` `KID_PROFILES`, `dashboard/serve.py` `KID_PROFILES` 세 곳을 함께 고치면 됩니다.

**Q. git 관련 에러가 떠요.**
- 글 파일을 바꿀 때 대시보드가 저절로 저장 기록(git 커밋)을 남기려 합니다. `user.name`이 없다고 나오면 아래를 한 번 실행하세요.
  ```bash
  git config --global user.name "아빠"
  git config --global user.email "dad@family.local"
  ```
- 기록을 남기지 않고 싶으면 `--no-git`으로 켜세요.

**Q. 지수 칸에 "지수를 불러오지 못했어요"가 떠요.**
- 정상입니다. 실시간 지수는 따로 연결해야 합니다(9번 절). 연결하지 않으면 그 칸만 그렇게 뜹니다.
